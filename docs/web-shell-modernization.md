# 叙叨 Web 壳层现代化 — 方案 B

> 目标：在不重写路由/IM 状态机的前提下，把上游「左竖栏 + Semi」骨架升级为更现代的桌面 IM 壳层。  
> 品牌：叙叨 / Shudo · 主色 `#FF4500`（暗色 `#FF6B35`）。  
> 视觉方向：**明亮工作台** — 浅灰分层表面、橙色点缀、圆角克制、阴影轻；暗色用深灰分层，非纯黑霓虹。  
> 明确不做：Liquid Glass 照搬 iOS、紫色渐变主题、奶油+赤陶风、整页卡片堆砌。

## 现状

| 区域 | 现状 | 问题 |
|------|------|------|
| Token | `App.css` 少量 `--wk-*` | 表面/边框/圆角/字号不全，暗色不分层 |
| 左轨 | `tab_normal_screen` 窄竖栏 | 像旧版 IM，选中态弱、设置菜单简陋 |
| 会话列 | `Pages/Chat` + `ConversationList` | 行高偏高、选中/悬停粗糙 |
| 会话区 | `Conversation` | 顶栏/输入区偏「工具条」，不够一体 |
| 浮层 | 斜杠 / `@bot` / Hermes | 功能已齐，视觉未跟新壳 |

能力层（Hermes / 斜杠 / inline / 翻译）**只跟样式与容器，不改协议**。

## 目标壳层（信息架构）

```
┌────┬──────────────┬─────────────────────────────┬────────┐
│ 轨 │  会话列       │  会话内容                     │ 可选   │
│ 64 │  ~300px      │  顶栏 + 消息流 + 输入底栏      │ 设置   │
│ px │              │                              │ 抽屉   │
└────┴──────────────┴─────────────────────────────┴────────┘
```

- **图标轨**：头像 + 消息/联系人等图标；选中为浅底圆角块 + 主色指示条  
- **会话列**：标题「消息」+ 搜索；列表更密、选中表面色、未读点更清晰  
- **内容区**：轻顶栏；消息区留白；输入区做成底栏「表面条」（非悬浮卡片堆）  
- **右栏**：沿用现有频道设置抽屉，样式跟 token

## 阶段与交付

### Phase 0 — Design tokens（约 0.5–1 天）✅ 起点

文件：`packages/tsdaodaobase/src/App.css`（及必要时 `App.tsx`）

新增/规范：

- 表面：`--wk-surface-app` / `--wk-surface-rail` / `--wk-surface-panel` / `--wk-surface-raised`
- 文字：`--wk-text-primary` / `--wk-text-secondary` / `--wk-text-tertiary`
- 边框：`--wk-border` / `--wk-border-subtle`
- 形状：`--wk-radius-sm|md|lg`、`--wk-space-*`
- 交互：`--wk-hover` / `--wk-active` / `--wk-focus-ring`
- 气泡：保留发送浅蓝思路，或微调为更低饱和（仍非卡片堆）
- 字体：从 Roboto 默认栈改为更现代的系统优先栈（避免 Inter 作为品牌字体）
- 暗色：完整映射上述 token

验收：明/暗切换后主壳无「裸白块」；Semi primary 仍跟叙叨橙。

### Phase 1 — 主壳三栏（约 2–3 天）

文件：

- `apps/web/.../tab_normal_screen.{tsx,css}`（及 `tab_low_screen` 同步关键样式）
- `Pages/Chat/index.{tsx,css}`
- `ConversationList/index.{tsx,css}`

改动：

1. 左轨宽度、背景、选中态、头像尺寸、底栏设置弹出层现代化  
2. 会话列：搜索条圆角输入、列表行高 ~64–72、选中/悬停用 surface token  
3. Chat 左右分栏边线改为 subtle border；标题层级下调（避免「大字报」）

验收：首屏一眼是「轨 + 列 + 内容」；选中会话清晰；暗色一致。

### Phase 2 — 会话区（约 2–3 天）

文件：`Conversation/index.{tsx,css}`、`MessageInput`、消息气泡相关 CSS、`HermesAudioBar`

改动：

1. 顶栏：更薄、底部分割线、操作图标统一  
2. 消息流：气泡圆角/间距；系统提示更轻  
3. 输入底栏：一体表面 + 内边距；工具图标对齐；富文本面板边线跟壳  
4. 音频顶栏跟新顶栏视觉统一

验收：打开会话后「顶栏—消息—输入」一条竖向节奏；无多余卡片框。

### Phase 3 — 浮层与 Hermes 跟壳（约 1–2 天）

文件：斜杠面板、inline GIF 面板、Hermes 卡/表、翻译气泡样式

改动：统一圆角、边框、阴影 token；主色仅用于强调与 CTA。

验收：`/`、`@bot`、审批卡、表格弹层不「跳出」新壳。

### Phase 4 — 登录 / 空态 / 扫尾（约 1 天）

登录页品牌「叙叨」大信号；空会话占位；`:82` 重建说明更新。

## 非目标（本轮不做）

- 重写 React 路由或换 UI 库（仍用 Semi）
- Electron/Tauri 专属壳大改（随 Web CSS 自然受益即可）
- iOS 像素级对齐 / Liquid Glass
- 管理端 `:83`

## 风险与策略

| 风险 | 策略 |
|------|------|
| 全局 CSS 回归 | 以 token 替换颜色为主，少改 DOM；每 Phase 后 `yarn dev` 冒烟 |
| `tab_low_screen` 分叉 | Phase 1 同步关键 CSS，或抽公共 rail 样式 |
| 暗色漏网 | Phase 0 先铺全 token，后续组件只引用变量 |
| 构建产物 | 开发看 `:3000`；稳定后再 `yarn build` + 重建 `:82` |
